# reports/

Browsers save downloads to their own download folder and cannot write here directly. After using
**Report → Download PDF / CSV / Detection Image** in WasteScan, move the files into this folder if you want to keep
reports together with the project.

File names follow `WasteScan_<image-name>_<yyyymmdd-hhmm>_report.pdf | _results.csv | _detection.png`.
